# GPC SHI 2.0

โปรแกรมรวมเครื่องมือ (จับเวลา รูปภาพ ตัดต่อ เครื่องคิดเลข ย่อไฟล์ โน๊ต เกม ส่อง Discord ฯลฯ)
สร้างโดยทีม GPC STUDIO

## สร้างไฟล์ .exe ผ่าน GitHub (ไม่ต้องลงอะไรในเครื่อง)

1. สมัคร/เข้าสู่ระบบ https://github.com แล้วกด **New repository** ตั้งชื่ออะไรก็ได้ (เลือก Private ก็ได้)
2. กด **uploading an existing file** (หรือ Add file → Upload files)
   แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดในซิปนี้** ไปวาง **รวมโฟลเดอร์ `.github`** ด้วย (สำคัญมาก)
   จากนั้นกด **Commit changes**
   - ถ้าโฟลเดอร์ `.github` ไม่ติดมา ให้กด Add file → Create new file พิมพ์ชื่อ `.github/workflows/build.yml`
     แล้วคัดลอกเนื้อหาจากไฟล์ build.yml ในซิปไปวาง
3. ไปที่แท็บ **Actions** ถ้ามีปุ่มให้เปิดใช้งาน ให้กดอนุญาต
   - เมื่อ Commit เสร็จ ระบบจะเริ่มสร้างให้เองอัตโนมัติ (หรือกด **Build Windows EXE → Run workflow**)
4. รอประมาณ 5-10 นาที จนขึ้นเครื่องหมายถูกสีเขียว
5. กดเข้าไปที่การรันล่าสุด เลื่อนลงไปหัวข้อ **Artifacts** แล้วดาวน์โหลด **GPC-SHI-2.0-Windows**
   แตกไฟล์จะได้
   - `GPC-SHI-2.0-Portable.exe` เปิดใช้ได้เลย ไม่ต้องติดตั้ง
   - `GPC-SHI-2.0-Setup.exe` ตัวติดตั้ง มีทางลัดบนเดสก์ท็อป

### อยากได้ลิงก์ดาวน์โหลดถาวร (Releases)
ที่หน้าหลักของ repository กด **Create a new release** → ตั้ง tag เป็น `v2.0.0` → Publish release
ระบบจะสร้าง .exe แล้วแนบไว้ใน Releases ให้อัตโนมัติ

## ถ้าได้ไฟล์เก่า (เช่น GPC SHI Setup 1.0.0.exe)
ชื่อไฟล์ `GPC SHI Setup 1.0.0.exe` มาจากโค้ดรุ่นเก่า (เวอร์ชัน 1.0.0) ไฟล์ของรุ่นนี้ต้องชื่อ `GPC-SHI-2.0-Setup.exe` ให้เช็กตามนี้
1. เปิดไฟล์ `package.json` ใน repository ต้องเห็น `"version": "2.0.0"` ถ้าไม่ใช่ แปลว่าไฟล์ใหม่ยังไม่ถูกอัปโหลดทับ
2. ลบไฟล์ทั้งหมดใน repository แล้วอัปโหลดใหม่ทั้งชุดจากซิปนี้ (หรือสร้าง repository ใหม่เลยง่ายสุด)
   ต้องมีโฟลเดอร์ `.github/workflows` เพียงไฟล์เดียวคือ `build.yml` ถ้ามี workflow เก่าอยู่ ให้ลบทิ้ง
3. เปิดแท็บ Actions เลือกการรัน **ล่าสุดที่อยู่บนสุด** แล้วดู Artifact ชื่อ `GPC-SHI-2.0-Windows-run<เลขรอบ>` (เลขรอบต้องมากกว่ารอบก่อน)
4. ในหน้ารันมีขั้นตอน **Show what is being built** ให้กดดู ต้องขึ้น `version=2.0.0` และ `<title>GPC SHI 2.0</title>`
5. ถ้าดาวน์โหลดจาก Releases ให้เช็กว่าเป็น release ล่าสุด (ถ้าตั้ง tag เดิมซ้ำ ระบบจะไม่สร้างใหม่ ให้ใช้ tag ใหม่ เช่น `v2.0.1`)

## ข้อควรรู้
- Windows อาจขึ้นหน้าต่าง SmartScreen เพราะโปรแกรมไม่มีลายเซ็นดิจิทัล ให้กด "ข้อมูลเพิ่มเติม" → "เรียกใช้อยู่ดี"
- รูป โน๊ต และปกที่ตั้งไว้ เก็บในเครื่องที่ใช้โปรแกรม (ไม่ซิงก์ออนไลน์)
- ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และปกแมพเกม
- แถบ "ส่อง": ตรวจเซิร์ฟเวอร์จากลิงก์เชิญได้ทันที ส่วนชื่อ/โปรไฟล์ของบัญชี ต้องใส่ Bot token ของคุณเอง
  (ขอฟรีที่ discord.com/developers/applications → New Application → Bot → Reset Token) ห้ามแชร์ token ให้ใคร
- Private repository ใช้นาที GitHub Actions ฟรีได้จำกัดต่อเดือน (Windows นับเป็น 2 เท่า) Public ใช้ฟรีไม่จำกัด

## สร้างในเครื่องเอง (ทางเลือก)
ติดตั้ง Node.js แล้วดับเบิลคลิก `build.bat` (ได้โฟลเดอร์โปรแกรมใน dist) หรือ `build-installer.bat` (ตัวติดตั้ง) หรือ `run-test.bat` เพื่อลองเปิดก่อน
